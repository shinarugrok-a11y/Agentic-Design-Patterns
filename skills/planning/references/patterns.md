# Planning patterns (Ch 6)

Two notebook variants: CrewAI planner-writer, OpenAI Deep Research API.

Pattern A — CrewAI planner: `Agent(role='Article Planner and Writer', goal=...)` with `ChatOpenAI(model='gpt-4-turbo')`; planner `Task` emits an outline, writer `Task` executes it via `Crew(Process.sequential)`.

Pattern B — Deep Research API: `OpenAI` client with researcher `system_message` ("data-rich insights, reliable sources, inline citations") + user research question; long-horizon retrieval + synthesis.

Prompt templates: planner prompt demands numbered steps each with owner-tool, inputs, and done-criteria. Always include a replan trigger ("if observation contradicts assumption N, replan from step K").
